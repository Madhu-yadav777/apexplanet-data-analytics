# Dashboards

This directory will contain interactive dashboard files for the ApexPlanet Data Analytics project.

## Planned Dashboard Contents (for future tasks)

- **Revenue by Product Category** - Interactive bar chart with filters for date range and region
- **Time Series Sales Trend** - Monthly sales with zoomable time window and YoY comparison
- **Customer Demographics** - Age/gender distribution with segmentation options
- **Payment Method Analysis** - Order counts and revenue by payment method over time
- **Geographic Heatmap** - Sales by city/state with drill-down capability
- **Product Performance Matrix** - Revenue vs quantity sold with bubble size for profit margin
- **Customer Lifetime Value** - Top customers by total spend and frequency
- **Discount Impact Analysis** - Relationship between discount level and customer rating

## Suggested Tools

- **Plotly Dash** - For Python-based interactive dashboards
- **Streamlit** - For rapid prototyping of data apps
- **Power BI / Tableau** - For enterprise BI connectivity
- **Jupyter Voila** - To convert the EDA notebook into a standalone web app
